# Security policy

## Reporting a vulnerability

Please **don't** report security problems in public issues, discussions or pull requests.

Report them privately through GitHub: [**Report a vulnerability**](https://github.com/getdokan/flycommerce-app-examples/security/advisories/new). Only the maintainers can see the report.

Please include the example affected, what an attacker can do, and the steps to reproduce it.

## What happens next

- We acknowledge the report within **3 business days**, and send a first assessment within **10 business days**.
- We fix confirmed issues in the example, and credit you unless you'd rather we didn't.

Examples are copied into real apps, so a flaw here may also be in apps built from it. We say in the fix which versions of an example were affected.

## Scope

In scope: the code in this repository.

The SDK packages are covered by [flycommerce-sdk's policy](https://github.com/getdokan/flycommerce-sdk/blob/main/SECURITY.md). FlyCommerce's hosted services (the dashboard, stores, the APIs) are out of scope here; report those through the same link, and we'll route them to the right team.
