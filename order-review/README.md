# Order Review

Hold big orders until you've checked them. Orders whose total is above a limit the merchant sets land in a Review queue inside their FlyCommerce dashboard, and the merchant puts them on hold or releases them.

> **Preview.** This example installs once the FlyCommerce app SDK is on npm.

## Run it

```bash
npm install
npm run dev
```

Then open the example dashboard at http://127.0.0.1:4003/apps/queue. No FlyCommerce account needed: `npm run dev` runs everything against `@flycommerce/app-emulator`.

To build it yourself, step by step, follow [TUTORIAL.md](TUTORIAL.md).
